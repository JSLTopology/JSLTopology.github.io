# Juseop Lee — Academic CV

The source of the public CV is Juseop_Lee_CV.tex.

- Edit the LaTeX file on Overleaf (pdfLaTeX) or locally.
- A GitHub Actions workflow compiles the PDF when this source is changed on master, and commits it to files/Juseop_Lee_CV.pdf.
- The website /cv/ page links to the compiled PDF and this LaTeX source.

The source is self-contained and does not need the resume.cls file missing from the original template.
